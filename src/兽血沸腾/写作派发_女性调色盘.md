## 四、`性格调色盘.yaml` 结构（照抄这个骨架）

```yaml
@@private
<%_ const chap = getvar('stat_data.剧情.章节序号', { defaults: 0 }); _%>
<%_ if (chap < {T1}) { _%>
性格调色盘:
  底色: {四个分支必须同一个词}
  主色调:
    - …
  性格点缀:
    - …
  {特质}衍生一: …
  {特质}衍生二：…
  {特质}衍生三: …
<%_ } else if (chap < {T2}) { _%>
…（同样结构，底色相同）
<%_ } else if (chap < {T3}) { _%>
…（同样结构，底色相同）
<%_ } else { _%>
…（同样结构，底色相同）
<%_ } _%>
{跨阶段通用衍生}衍生一: …      # 落在所有 if 之外，无条件生效
{跨阶段通用衍生}衍生二: …
对角色的理解与思考:
  关于{名}: |
    …
  总结: |
    这就是{名}的性格调色盘，在这个调色盘上有着无数的颜色…
```

硬规则（`multi-stage.md` L11-21）：
1. **底色四个分支必须是同一个词**。
2. 阶段专属衍生是该阶段**新出现**的行为，不是上一阶段的升级版。
3. **通用衍生放所有 `if` 之外**，跨阶段始终存在。
4. 每个性格色 2-3 条衍生，重要的可更多。
5. 衍生写具体场景与行为，不写抽象定义。
6. **EJS 分支互相不可见，禁止写「比前一阶段更…」这类跨阶段比较**。
7. 装饰器与内容之间不能有空行；控制行只能独占一行且为 `<%_ … _%>`。
