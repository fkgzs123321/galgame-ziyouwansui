# 写作派发：女性角色补全（升格为「角色」）

## 一、任务

把下列 8 位女性 NPC **从 `NPC` 类型升格为 `角色` 类型**，每位产出两个文件：

```
src/兽血沸腾/世界书/角色/{名}/基础信息.yaml
src/兽血沸腾/世界书/角色/{名}/性格调色盘.yaml
```

升格后**原 `世界书/NPC/{名}.yaml` 会被删除**（由主代理处理），所以 NPC 文件里的内容必须被完整吸收进这两个新文件，不许丢信息。

## 三、`基础信息.yaml` 格式

严格用这一套键（**不写性格**，`basic-info.md` L9）：

```yaml
基本信息:
  姓名: …
  性别: 女
  年龄: …            # 原作没写就整行不要
  种族: …
  身份: …
  # 其他身份相关键：来历/归属/爵位/职分… 按需

外貌特征:
  # 只写「遮住名字还能认出是谁」的特征；禁万能美人描写（精致/白皙/好看）
  # 标志性装扮、异色特征、体型显著特点、能记住的细节

背景设定:
  # 只写「让她变成现在这样」的关键事件，写具体画面不写评价

能力体系:
  # 种族异能 / 法术 / 装备 / 短板

关系设定:
  {对方名}:
    关系定位: …
    互动方式: …
```

参考已完成的范例：`世界书/角色/凝玉/基础信息.yaml`、`世界书/角色/黛丝/基础信息.yaml`。

## 四、`性格调色盘.yaml` 格式

**文件首行必须是 `@@private`**，第二行起是 `const`，然后才是正文：

```yaml
@@private
<%_ const aff = getvar('stat_data.关系.{名}.好感度', { defaults: 0 }); _%>
<%_ if (aff < 20) { _%>
性格调色盘:
  底色: …
  主色调:
    - …
  性格点缀:
    - …
  {特质}衍生一: …
  {特质}衍生二: …
<%_ } else if (aff < 50) { _%>
…（同样结构）
<%_ } else if (aff < 80) { _%>
…（同样结构）
<%_ } else { _%>
…（同样结构）
<%_ } _%>
{跨阶段通用衍生}衍生一: …     # 落在所有 if 之外，无条件生效
{跨阶段通用衍生}衍生二: …
对角色的理解与思考:
  关于{名}: |
    …
  总结: |
    这就是{名}的性格调色盘，在这个调色盘上有着无数的颜色…
```

**硬规则**（`multi-stage.md` L11-21）：

1. **底色不随阶段变化**——四个分支的底色必须是同一个词。
2. **阶段专属衍生是该阶段「新出现」的行为，不是上一阶段的升级版**。
3. **通用衍生放所有 `if` 之外**，跨阶段始终存在。
4. 每个性格色至少 2-3 条衍生，重要的可以更多。
5. 衍生写**具体场景和行为**，不写抽象定义。要写出「只有这个角色才会有的动作和说话方式」。
6. 边界值不重叠不遗漏。
7. **EJS 分支之间互相不可见，绝对不许写「比第一阶段更克制」这类跨阶段比较**（`rules-check.md` L184）。

EJS 语法硬约束（`ejs/guide.md`）：

- 控制行只能是 `<%_ … _%>` 独占一行，**装饰器与内容之间不能有空行**。
- 一个条目**只用一个装饰器**（这里就是 `@@private`）。
- `@@private` 已为该条目包裹块作用域，短名（如 `aff`）条目内有效。
- `@@if` 不许裸引用标识符。
- 不要用 `<%= %>` 或 `<% %>`，统一 `<%_ _%>`。

参考范例：`世界书/角色/谭雅/性格调色盘.yaml`（4 分支 + 结尾通用衍生 + 理解与思考）。

## 五、通用的负面清单（会被 `check-banned.mjs` 拦下）

**全文杜绝：**
- 破折号 `——`（一个都不许有）
- 八股模糊比喻：`似乎` `几乎` `仿佛` `如同` `宛如` `好似` `犹如`
- 陈旧意象：`像小兽` `投石入湖` `心湖泛起` `涟漪` `嘴角微微上扬` `眼中闪过一丝` `带着…的口吻`
- 情绪套话：`陷入极大的恐惧` `万念俱灰` `心头一震` `心中一凛` `不由自主地` `不禁`
- 否定转折句式：`不是…，而是…`
- 过度心理：`他心想` `她心想` `心中暗道` `暗自思忖` `内心深处`
- 元叙事：`本文将` `本条目` `如前所述` `综上所述` `值得注意的是`
- 翻译腔：`一个…的存在` `进行了一次` `做出了一个`
- 占位符：`待补` `待确认` `TODO` `FIXME`

**另有：**
- 不许出现 `#` 注释行。
- 不许编造原作没有的事实。素材里没有的不写；确实没有就**不写那一项**，不要写「原作未提及」之类的元叙述。
- 不写未成年角色的露骨内容。

## 六、禁止事项

- **不许碰 `src/兽血沸腾/tavern-cards-state.json`**。
- **不许运行 `tavern-cards-forge.mjs`**（注册由主代理统一做）。
- 不许改 `schema.ts`、`initvar.yaml`、界面代码、其他角色文件。
- 只写你自己负责的那 2 位角色的 4 个文件。
