# Design Spec — 兽血沸腾

> 本文件为跨 skill 交接物：tavern-design 写入叙事设计段，tavern-ui 追加 UI 段，tavern-cards 消费。
> 素材：骷髅精灵《兽血沸腾》全本（784 章 / 约 487 万字），转化成果见 `故事大纲.yaml`。

## 项目定位

- 项目名称：兽血沸腾
- 形式：角色卡（世界书内嵌）
- 主题：同人改编 — 异世界大陆争霸与领地经营的角色扮演
- 体验目标：**四项体验全开**（用户明确四选全要）
  - 主线史诗重演：从荒岛求生到比蒙领主、再到爱琴大陆决战，按原作战线推进
  - 角色关系养成：海伦、凝玉、艾薇尔等核心角色的好感与关系推进作为主要驱动力之一
  - 翡冷翠领地经营：建造、招揽部族、管理领地，具备模拟经营的循环
  - 自由冒险沙盒：不绑死主线，可在爱琴大陆自由探索、接任务、经商、征战
- 情感落点：沉浸 + 陪伴 + 爽感释放。玩家既是被命运推着走的穿越者，也是能亲手改写爱琴大陆格局的领主

## 世界观概念

- 舞台：**爱琴大陆**——人类、比蒙（兽人）、精灵、矮人、海族、龙族等多族共处的异世界；另有丝绸大陆、澈桑大陆、魔界、冥界
- 现实性基线：完全架空（含穿越设定）
- 世界基调：**危机四伏中带着喧闹生机**。千年前海加尔战役兽人惨败退守多瑙荒原，人类与比蒙千年对峙，海族封锁海路，魔族蠢蠢欲动
- 核心规则（原作特有，**必须避开网文通用套路**）：
  - 力量体系为**比蒙圣坛祭祀**：风语祭祀 → 灵魂祭祀 → 战争祭祀 → 权杖祭祀 → 维安大萨满 → 十二主祭 → 红衣大祭司（原文权威七阶）
  - 祭祀是**辅助兵种**，身体孱弱不堪一击，靠战歌光环加持战友，从不肉搏
  - 祭祀以**歌力**驱动战歌（对应人类魔力），靠冥想积累；战歌加持范围约三十米起，有沙漏时限
  - **战歌永不反噬，人类魔法才会致命反噬**——这是原作者反复强调的体系性差异
  - 人类魔法师靠吟唱 + 香料 + 卷轴施法，吟唱期间被打断则法术失败并遭反噬；分七级体系
  - 祭祀核心限制：**每个灵魂歌者终生只能有一只魔宠**；**智慧启蒙一生只能用一次**
  - 比蒙自称比蒙、有人类是其一支（芒克族猴人）进化而来的文明史；国王十年一任，可由五大贵族推举挑战者比武夺位
- 通用职衔「魔歌祭祀」「战歌祭祀」「英雄阶」「传奇阶」**原作不存在，禁止使用**

## 角色方向

- **刘震撼（李察）**：主角，**必须做成完整可扮演设定**（用户明确要求，不因玩家可扮演任意角色而省略）
  - 穿越前为现代**侦察兵**（南疆战场中弹），性格「有点小坏，没那么多原则」
  - 穿越落点为一具**匹格族猪头人**的身体，原身被族人视为懦弱贪懒
  - 天生灵魂歌者，却因魔宠非自然死亡遭**血之祭奠的诅咒**，正牌战歌全部失效
  - 破局方式：**用汉语自创战歌**，效果仍是正宗比蒙战歌——这是其独有路线，也是异端身份的风险来源
  - 核心矛盾自我定位：蠢蛋之族匹格猪头人 / 天生灵魂歌者 / 被诅咒致战歌失效的祭祀 / 独创另一种战歌 / 祭祀中最强壮的大力士
  - 成长轨迹：龙祭祀（官方不承认）→ 战争祭祀 → 圣奇奥（血系法术）→ 神曲萨满（无实权荣誉头衔）→ 花王韦舵
  - 班底：果果（霜雪皮丘兽，未签灵魂契约）、海伦.列娜、凝玉、仙女龙若尔娜、熊猫武士、猛犸大力士、三大金人等
- **海伦.列娜**：福克斯族狐人，战争祭祀，十五岁；按战神指引认定「李察」为其未来丈夫之名；情感主线核心
- **凝玉**：摩韶族人鱼，海族公主，性情蛮横，与主角关系张力强
- **艾薇尔**：西雅海国美人鱼公主，王族波塞顿家出身，天生水系大魔法师。她跟着一个比蒙出走，海国视之为对全族血统的侮辱，贝肯鲍尔征召预备役要血洗比蒙王国把她夺回去。**她是海族立场，不是人类侧**；她的冲突对象是自己的父兄与整个西雅海国
- **人类侧角色**：人类诸国的代表是圣弗郎西斯科帝国（三大军事强国之一，白银基座战士被主角一人干掉十分之一，成为其对蒙开战的理由）、庞贝帝国与圣荷西帝国；教会的代表是圣保罗教廷（第一大宗教，帝梵西城，教皇保罗·马尔蒂尼与十二枢机主教），武装为金棕榈与宝剑橡叶两支圣骑士团。人类早期与比蒙千年对峙，魔族压境后共组爱琴同盟、在叹息之墙阻击海族主力
- **`<user>` 定位**：**不作限定**（用户明确「都可以扮演，不限定」）。玩家可扮演刘震撼、可扮演海伦或其他角色、也可作为原创穿越者进入爱琴大陆。世界书需为各主要角色备好完整设定，使任一视角都能成立
- 角色弧光方向：成长为主，兼有反转（主角以化名「李察」周旋诸国，原作终盘揭示他既是位面英雄也是大战幕后黑手）

## 互动与动态需求

- 主要互动方式：对话扮演 + 剧情推进 + 领地经营决策 + 战斗与战歌策略
- 玩家能动性范围：**半引导**（主线节点存在，但允许自由发挥与偏离）
- 需追踪的动态概念：
  - 角色关系：核心角色好感度 / 信任度 / 关系阶段
  - 剧情进度：当前卷 / 当前章节节点 / 已触发原作事件
  - 领地经营：翡冷翠的资源、建筑、人口、兵力、声望
  - 战斗状态：主角身体状况、歌力 / 魔力、魔宠状态、祭祀阶位
- 反馈循环节奏：短期（单次互动、好感变化）+ 长期（领地等级、阶位晋升、剧情推进）
- 角色对玩家行为的反应走向：依原作性格基调，海伦温柔执着、凝玉蛮横直接、艾薇尔立场驱动

## SFW / NSFW

- 分级：**NSFW 全开，贴近原作**（用户明确选择）
- 关系结构：**后宫 / 多人**，贴合原作（海伦、凝玉、若尔娜等）
- NSFW 定位：**主线内容**，非可选分支；原作本身含大量露骨描写与荤段子风格
- 笔触文风：**贴近原作的露骨直白**，保留原作粗俗幽默与荤话风格，不做含蓄化改写
- 硬性边界：以原作内容为范围；未在原作出现的极端内容不主动添加

## 剧情设计

- 原作 784 章，**要求全部覆盖**（用户明确「全部做出来」），转化产出 `故事大纲.yaml` 逐章 notes
- 卷结构（依 `tools/素材结构分析报告.md` 考证）：
  1. 荒岛篇（穿越求生，遇海伦）
  2. 胸罩岛篇（受诅咒、自创战歌、爵位）
  3. 海上篇（海族、人鱼凝玉）
  4. 多瑙大荒原篇（比蒙社会、部族、神庙）
  5. 博格村与翡冷翠初期（领主起步、领地经营）
  6. 翡冷翠领主期（建国、军事、外交）
  7. 比蒙王国纵横与大陆决战（魔族入侵、终盘）
- **暴露时机**：世界观基础（种族、祭祀体系、地理）在前面板即时给出；角色身世与历史（海加尔战役、诅咒真相）随剧情与关系推进逐步揭示；终盘反转（主角以「李察」之名做下的事被翻出）作为远期节点保留
- **控制策略**：以「当前剧情进度」变量控制剧情条目显隐，用阶段指导约束 AI 不提前跳到高潮；关键事件按原顺序排列，玩家自由度限于过程与结果细节
- **素材缺陷处理**（已考证，非考据失误）：
  - 源文本 idx 722–742 为 idx 703–721 的冗余副本 → 转化时去重，保留章号正确的一份
  - 第六百六十八章 ~ 第六百七十章原文缺失 → 忠于原文，不虚构补全
  - idx 711/712/722 章号错标 → 条目名照原文，notes 标注疑似错标
- 未确定部分：各开局点的具体切入章节待创作阶段与用户确认

## 风格意向

- 叙事视角：**第三人称**（贴合原作，同时便于任意角色视角）
- 语言风格：**口语化、粗俗幽默**，保留作者插话式吐槽与荤段子；适度文学化用于战争与史诗场面
- 文学密度：口语轻量为主，战争与领地建设场面适度修辞
- 描写侧重：对话与动作并重，兼顾心理与战场环境
- 情绪基调：**搞笑与热血交替**，荒岛求生段窘迫温情，战争段悲壮紧张，日常段喧闹欢脱
- 风格参考：以原作本身为唯一样本，刻意避开通用网文腔（尤其避免「魔歌祭祀」「英雄阶」等原不存在的术语）

## 开场构思

- 玩家进入世界的第一印象：**多入口**（用户明确「设几个不同的开局点和自定义」）
- 拟设开局点（创作阶段细化）：
  1. **荒岛求生**（原作起点）——最忠于原作的入口
  2. **翡冷翠领主**（领地经营入口）——直接进入经营线
  3. **比蒙王国/多瑙荒原**（自由冒险入口）——作为外来者进入
  4. **海族/人鱼线**（凝玉相关入口）
  5. **自定义开局**——玩家自定身份、种族、出身与进入点
- 开场信息密度：渐进揭示，避免开局抛设定
- 玩家首步引导方式：弱引导，给方向不锁死
- 开场形式偏好：**叙事式（叙事 + 表单组合）**，配合 frontend 界面提供开局选择表单
- 说明式开场白：需要（玩法与界面提示），置于游玩入口之前

## UI 设计

> 决策依据见同目录 `控制中心架构.md`。定位：**超重型游戏化控制中心**——战斗体系、技能树、领地经营是主体，状态显示只是其中一个页签。

### 视觉基调

#### 感官词

- **主调**：青铜祭坛的绿锈、兽皮与粗麻的哑光、篝火的橙红余烬
- **祭祀**：战歌光环的同心圆、沙漏计时、石刻阶位徽记
- **领地**：夯土与红土高原的赭色、木栅与石垒的层叠、账册的格线
- **战斗**：金属划痕、血渍暗红、结界裂纹、暴风眼的压暗
- **终盘**：空间裂缝的冷紫裂口、燃烧的星屑、灰烬飘落

#### 交互人格

祭祀是辅助者：它不替你出手，只把光环铺在你脚下。UI 的交互人格据此定为「沉稳的随军书记官 + 战歌加持」，而非轻佻的助手。

| 维度 | 明线（日常 / 经营 / 社交） | 暗线（战斗 / 终盘 / 诅咒） |
|------|--------------------------|--------------------------|
| 语速 | 从容，像翻阅账册 | 短促，像传令兵报数 |
| 音量 | 低沉平稳 | 压过鼓点 |
| 动作 | 摊开一卷新的账页 | 一层光环叠上另一层 |
| 距离 | 站在你侧后方半步 | 光环以你为圆心向外推 |
| 回应 | 先报数，再给建议 | 先给结果，再补战报 |

### 组件构思

#### 信息优先级

- **始终可见**（顶栏）：当前卷与章节节点、主角阶位、生命 / 歌力双条、当前区域与时段、`<user>` 身份
- **展开可见**（八面板页签）：战斗、技能树、领地、图鉴、编年史、魔宠装备、后宫孕事
- **情境可见**：战斗面板仅在 `战斗.进行中 === true` 时自动切到前台并高亮；`主角.诅咒.血之祭奠 === true` 时顶栏常驻诅咒印记；`后宫.孕事` 有进行中条目时页签出现提示点；`系统.规则开关.孕事系统 === false` 时该页签隐藏

#### 布局模式

**混合型（仪表盘 + 折叠网格）**，理由：四类体验并置，玩家需要在「领地资源」「技能解锁」「敌我单位」之间横向对比数字（展示型特征），同时战斗与孕事是情境触发（沉浸型特征）。纯仪表型会牺牲立绘与文本观感，纯叙事型无法承载数值对比。

#### 双线叙事的布局体现

不是明暗双线，而是「平时 / 战时」两态——比蒙祭祀的日常与出征确实是两种生活。

- **结构相同只换配色的区块**：顶栏、页签条、总览仪表盘。战时把 `--sb-bg` / `--sb-panel` 整层压暗，描边改走 `--sb-life`
- **战时新增或变形的区块**：战斗面板自动抢占前台；顶栏生命条加脉动；歌力条显示沙漏倒计时；技能树中不可用节点（歌力不足 / 阶位不够）整体降饱和
- **切换条件**：`战斗.进行中 === true` 进入战时态；`战斗.进行中 === false` 且 `主角.生命.当前 / 主角.生命.上限 < 0.3` 进入「重伤恢复」过渡态，顶栏整体转为 `--sb-life` 单色

#### 独特性自检

1. **去色辨识度**：布局本身有辨识度——八面板控制中心内嵌「七阶石刻阶位徽记」与「战歌光环同心圆」两个形状母题，即使灰阶化仍能靠同心圆加持槽与阶位刻度区分于常见状态栏
2. **唯一元素**：**战歌加持槽 + 沙漏时限**。原作设定战歌光环有「五盎司沙漏」的时限、且「被打断则凝聚的歌力瞬间失效」，这是本作独有的战斗机制，其他卡不会有对应呈现；另有「每个灵魂歌者终生只能有一只魔宠」在魔宠舱体现为不可增改的单一主位
3. **过渡是否讲故事**：阶位晋升时石刻徽记要重新镌刻（不是换图标），战歌加持槽叠层时按光环实际覆盖范围做同心圆扩散（对应「战争祭祀加持范围方圆三十米」），诅咒生效时顶栏出现不可抹除的印记——每次过渡都在讲原作规则，而非单纯状态切换
