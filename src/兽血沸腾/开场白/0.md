### 世界观
爱琴大陆。比蒙、人类、海族、龙族、唐藏、魔族共处一片大陆，谁都在算计谁。

你是这片大陆上的一个人。你可能是蠢笨的匹格族猪头人，可能是天生灵魂歌者，可能是统率一方的翡冷翠领主，也可能是从别处掉进来的外来客。身份由你在开局时决定。

### 玩法说明

**主线史诗重演**
原作七百八十四章的剧情节点已经全部写进世界书。你走到哪里，哪里的舞台就会亮起来。你可以顺着原作的轨迹走，也可以拐去别的地方，已经发生过的分歧会被记下来。

**角色关系养成**
每一个重要角色都有自己的性格调色盘。同一句话，她对你初见时会怎么答、成了妻子之后又会怎么答，是两回事。好感度、信任度、关系阶段都会随你的行为变化。

**翡冷翠领地经营**
拿到封地之后，人口、民心、治安、七种资源、建筑、兵力、附庸族，都在控制中心的「领地经营台」里。一千人口是贵族监察院的底线，低于这条线，你的封地会被别人兼并。

**自由冒险沙盒**
没有必须做的事，也没有必须去的地方。你可以带一队人马去南十字星森林猎魔兽，可以在威瑟斯庞的酒馆里听消息，也可以什么都不干，在夏宫的露台上抽一整天的雪茄。

### 控制中心

右下角的控制中心是本卡的主界面，一共八个面板：

| 面板 | 用途 |
|---|---|
| 总览仪表盘 | 时间、地点、身份、阶位、生命歌力体力、主线进度 |
| 战斗面板 | 敌我阵列、战歌光环、逐回合战报，战斗在这里结算 |
| 技能树 | 战歌树、异体原、兵种树、领地科技树，外加自定义节点 |
| 领地经营台 | 资源收支、建筑、兵力、附庸族、施政 |
| 角色图鉴 | 所有登场角色的好感度、信任度、关系阶段与档案 |
| 剧情编年史 | 已触发事件、分歧记录、卷内节点回看 |
| 魔宠与装备舱 | 魔宠、装备栏、物品栏、异体原状态 |
| 后宫与家事 | 亲密记录、孕事、子嗣、成员名册 |

战斗由前端结算伤害与光环，我只负责把这一回合的厮杀写出来。你在面板上做的操作，我都当已经生效，直接接着往下写。

### NSFW 说明

本卡按原作尺度写。亲密场景不回避，后宫、孕事、子嗣都做成了独立面板。

如果你不想看这部分，在控制中心把「孕事系统」关掉即可，其余内容不受影响。
