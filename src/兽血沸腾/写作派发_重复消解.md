# 派发：跨条目重复消解（71 处）

## 一、背景

`src/兽血沸腾/tools/audit-cross-entry-dup-prose.mjs` 扫出 **71 处正文级重复**（>=20 字共同子串，已剔除 `参考语料:` 逐字引用块，所以这 71 处全部是**正文**，不是原文引用）。

依 `skills rules-check.md` L160-170 的「跨条目重复检查」：

> - L162 禁止把同一信息、同一行为锚点、同一人设特征在多条目间重复
> - L166 内容重复 → 保留职责最贴切的那条，**另一条删除该句**
> - L170 判定重复以「信息」为单位，不是「措辞」

**所以「换个说法重写一遍」不算修好。** 必须是：同一件事只在职责最贴切的那一个条目里讲，另一个条目把这句话**删掉或改成不含该信息的表达**。

## 二、职责划分（决定谁留谁删）

| 条目 | 职责 | 遇到重复时 |
|---|---|---|
| `基础信息.yaml` | 生平事实、身份、关系、能力、背景 | **生平事实归它**。它保留 |
| `性格调色盘.yaml` | 行为锚点（`衍生N`）：这个人在这个阶段**会做什么** | 它删掉被复述的**事实**，只留**动作** |
| `私密.yaml` | 身体底账、气味、分泌物、敏感带、名器、性癖 | 身体底账归它。生平事实让给 `基础信息` |
| `私密阶段.yaml` | 该阶段的**身体反应**与**主动性位移** | 它删掉被复述的事实与背景 |

**核心判据**：`性格调色盘` 的 `衍生N` 应该是「她做了 X」这种**可演的动作**，不该是「她经历过 Y」这种**背景陈述**。凡是 `衍生N` 里出现了与 `基础信息` 雷同的背景句，就把背景句删掉，只保留动作部分。

## 三、硬约束（不许破坏的东西）

1. **只改被点名的那些句子**。不许重写整个文件，不许顺手润色别的段落。
2. **不许打破 EJS 结构**：
   - `私密阶段.yaml` / `性格调色盘.yaml` 首行必须是 `@@private`
   - 控制行必须**独占一行**且严格写成 `<%_ ... _%>`
   - 分支数、`衍生N` 编号的连续性、每档键数**一律不变**
   - 装饰器与内容之间不能有空行
3. **阈值一个字都不许动**（改完要能和同角色的另一个文件对上）。
4. **不许丢信息**：删掉的那句话里，如果含有**别处没有**的信息，就不能删——要么保留在 `基础信息`，要么改写进职责正确的条目。**删之前先确认这条信息在职责该在的那个文件里已经有了。**
5. **不许出现禁用词**（见 `tools/check-banned.mjs`）：`——`、`似乎|几乎|仿佛|如同|宛如|好似|犹如`、`像小兽|投石入湖|心湖泛起|涟漪|嘴角微微上扬|眼中闪过一丝`、`陷入极大的恐惧|万念俱灰|心头一震|心中一凛|不由自主地|不禁`、`他心想|她心想|心中暗道|暗自思忖|内心深处`、`本文将|本条目|如前所述|综上所述|值得注意的是`、`待补|TODO|（略）` 等。
6. **不许写 `#` 注释行**。
7. 文件编码：**UTF-8 无 BOM、LF 换行、不用 TAB**。末尾保留一个换行。
8. **只许改派发给你的那几位**。不许碰 `tavern-cards-state.json`、不许跑 forge、不许动 `界面/` 下任何文件。

## 四、怎么自查

改完在 `C:\tavern_helper_template` 下依次跑：

```
node src/兽血沸腾/tools/audit-cross-entry-dup-prose.mjs
node src/兽血沸腾/tools/check-yaml.mjs
node src/兽血沸腾/tools/check-ejs.mjs
node src/兽血沸腾/tools/check-banned.mjs
node src/兽血沸腾/tools/check-structure.mjs
node src/兽血沸腾/tools/verify-female-batch.mjs
```

第一条的输出里，**你负责的角色应该降到 0 处**（或只剩确实无法处置的、并在回报里逐条说明理由）。后五条必须全绿：`check-yaml` fail=0、`check-ejs` 全部通过、`check-banned` 命中 0、`check-structure` 三类全 0、`verify-female-batch` 全部通过。

**注意**：并行跑的时候别的 agent 也在改别的角色，`audit-cross-entry-dup-prose.mjs` 的**总数**会变，你只要看**你那几位**的数字。

## 五、回报格式

逐条列出：角色 / 条目对 / 原句 / 怎么改的 / 这句信息现在落在哪个条目。最后附上五条校验器的输出末行。
