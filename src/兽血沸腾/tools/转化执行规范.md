## 一、任务性质

对 440 万字长篇小说的分片执行**材料转化**，产出供后续角色卡创作使用的故事大纲片段。依据：
- `C:\tavern_helper_template\.skills\tavern-cards\agents\conversion-agent.md`（身份与职责）
- `C:\tavern_helper_template\.skills\tavern-design\references\conversion\outline-spec.md`（大纲结构与记录规范）

## 二、输入输出

| 项 | 值 |
|---|---|
| 源分片 | `C:\tavern_helper_template\src\兽血沸腾\wip\chunks\{NNN}.txt` |
| 输出片段 | `C:\tavern_helper_template\src\兽血沸腾\wip\outline\{NNN}.yaml` |
| 章节索引 | `C:\tavern_helper_template\src\兽血沸腾\tools\chapter-index.json` |
| 结构报告 | `C:\tavern_helper_template\src\兽血沸腾\tools\素材结构分析报告.md` |

分片文件头部注释给出章节区间、行范围、首末章名——**仅供定位参考**，实际章节必须以正文中出现的标题为准。

## 三、核心要求

1. **逐章 notes**：为范围内**每一章**撰写 `chapters[].notes`，50-100 字，具体描述主要事件、新角色出场、关系变化、重要设定揭示。**一章都不能漏**。
2. **章节 name 逐字一致**：含空格、标点、全角括号、`{V第十二章}` 之类标记，原样保留（仅去首尾空白）。`quotes[].chapter` 必须与 `chapters[].name` 完全一致。
3. **全局信息**（全部顶层字段都要输出，即使为空也写空列表）：
   - `worldview`：世界规则、社会结构、历史背景、种族设定
   - `regions`：区域名 + 该区域下 `scenes`（只列原文出现的场景名）+ `description`
   - `factions`：势力名 + `summary` + `territory` + `key_members`
   - `characters`：每个有戏份的角色，`identity`/`personality`/`relationship` 各自一句话；可选 `gender`、`age` 或 `birth_year`、`appearance`、`quotes`
   - `items`：对剧情或世界观有重要意义的物品/能力/神器
   - `important_chapters`：关键转折、首次出现、名场面，含 `reason` 与可选 `quotes`
   - `style_hints`：`perspective`/`tone`/`mood`
   - `missing_names`：缺失的具体名称（地名类/角色名类/专有名词类）
4. **原文引用逐字照搬**：一个标点都不改，必须能在源分片中精确搜索到。不拼接不连续句子；每章最多 1-2 条；只收录人物塑造、剧情高潮、核心世界观揭示的关键原句。
5. **宁多勿少**：不因「这段不重要」跳过。禁止「等」「略」「待补充」「待定」等省略表述。
6. **不编造**：原文没说的不补全。

## 四、YAML 格式规范（违反会导致脚本报错）

- 2 空格缩进，**禁止 Tab**
- 冒号后必须有空格
- 同一层级不允许重复 key
- 字符串中**禁止使用英文双引号 `"`**，改用中文引号「」或 “”
- 列表项用 `- `（短横线加空格）

## 五、输出后必须自验

node "C:\tavern_helper_template\.skills\tavern-design\scripts\validate-conversion-outline.mjs" "<输出yaml绝对路径>" "<源分片绝对路径>"
