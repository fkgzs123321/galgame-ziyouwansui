# 兽血沸腾 · 补齐「性格调色盘」条目 · 派发说明

## 一、为什么补

`.skills` 的 `entry-types.md` 规定：**每个核心角色至少写 basic + personality（性格调色盘）**。
`创作规划.yaml` 的 `characters[]` 已为下列 10 人写明 `personality.{base,main,accent}`，
但 `entries[]` 里漏了对应的「性格调色盘」条目。补上。

另外 `tri-faceted.md` L7 规定：**三面性的前置是性格调色盘，没有调色盘的三面性是空壳**。
隆美尔与李察王子已有三面性条目，故必须补上调色盘。

## 四、多阶段格式（严格照抄）

文件首行必须是装饰器（`@@` 必须在文件首行，装饰器与内容之间**不能有空行**）：

```
@@private
<%_ const aff = getvar('stat_data.关系.黛丝.好感度', { defaults: 0 }); _%>
性格调色盘: 人的性格就像调色盘，底色是不变的内核，各阶段各有不同的主色调与点缀
底色: <不随阶段变化，只写一次>

<%_ if (aff < 20) { _%>
主色调: A、B
性格点缀: C

A衍生一: <具体场景与行为>
A衍生二: ...
A衍生三: ...
B衍生一: ...
B衍生二: ...
B衍生三: ...
C衍生一: ...
C衍生二: ...
C衍生三: ...
<%_ } else if (aff < 50) { _%>
主色调: D、E
性格点缀: F

... 每个性格 2 到 3 条衍生 ...
<%_ } else if (aff < 80) { _%>
主色调: G、H
性格点缀: I

... 
<%_ } else { _%>
主色调: J、K
性格点缀: L

... 
<%_ } _%>

<跨阶段通用衍生，放在所有条件之外>
X衍生四: ...
Y衍生四: ...

总结: |
  这就是<角色名>的性格调色盘，在这个调色盘上有着无数的颜色，任何时候都是由多种性格、行为、回忆组合驱动着<角色名>，并非单纯的一种颜色、一个标签。
```

**阶段边界不重叠不遗漏**：`< 20` / `< 50` / `< 80` / `else`（即 ≥ 80）。

宠物（果果、壹条）把变量名与路径换掉即可：

```
@@private
<%_ const loy = getvar('stat_data.魔宠.果果.忠诚', { defaults: 0 }); _%>
```
阶段用 `< 40` / `< 70` / `else`（三阶段）。

## 五、单阶段格式

**不要写 `@@` 装饰器，不要写任何 EJS**，纯 YAML：

```
性格调色盘: 人的性格就像调色盘，底色是不变的内核，主色调与点缀各有各的深浅
底色: <一句>

主色调: A、B
性格点缀: C

A衍生一: <具体场景与行为>
... 每个性格 3 到 5 条衍生 ...

对角色的理解与思考:
  关于A: |
    ...
  关于B: |
    ...

总结: |
  这就是<角色名>的性格调色盘，...
```

**单阶段条目的范文**：`src/兽血沸腾/世界书/角色/穆里尼奥/性格调色盘.yaml`（照它的骨架写，不要抄它的内容）。

## 六、硬性约束

### 格式
- UTF-8 无 BOM，纯 LF 换行，禁止 TAB，2 空格缩进
- `键: 值` 冒号后必须有一个空格
- 数据库格式（`键: 值` / 列表），**不是散文**
- 全文简体中文；禁止繁体与日文汉字
- 禁止占位符（`待补`、`TODO`、`XXX`、`（略）`、`...`）
- **XML 标签绝对不能写进内容文件**（`<character_personality>` 由注册时的 `contents` 外层加，不是内容文件的事）
- YAML 里禁止 ASCII 双引号 `"`；需要引号时用 `「」` 或 `“”`
- 一个文件里禁止 `---` 分隔线（会破坏 YAML 解析）

### 用词纪律（违反即返工）
- **破折号 `——` 全文杜绝**
- **禁止 `因为`、`本质上`、`其实`、`内心`**（调色盘尤其严格）
- 八股黑名单：`似乎`、`几乎`、`仿佛`、`如同`、`宛如`、`像小兽`、`投石入湖`、`心湖泛起涟漪`、`嘴角微微上扬`、`眼中闪过一丝XX`、`带着XX的口吻`、`陷入极大的恐惧`、`万念俱灰`
- 句式黑名单：否定转折（`不是A而是B`）、标签化、过度心理描写、空洞数字
- 禁止元叙事：不写「本条目的作用是」「这是设定」「原作里」
- 禁止跨条目重复与跨条目引用：不写「见XX条目」「如上文所述」
- 不做主观评价：不写「极美」「波澜壮阔」这类空泛形容
- 阶位只用真实七阶：风语祭祀 → 灵魂祭祀 → 战争祭祀 → 权杖祭祀 → 维安大萨满 → 十二主祭 → 红衣大祭司
- 人名写法以 `术语纪律.md` 为准（**艾薇尔**不是艾薇儿，**崔蓓茜**不是崔蓓西，**黛丝**、**若尔娜**、**歌坦妮**、**茉儿**）

### 写作质量
- 衍生写**具体场景和行为**，不写抽象定义
- 衍生要写出**这个角色自己才会有的动作与说话方式**，让人不看名字也能分清是谁
- **一句一意**；不堆形容词
- 不许编造。原作没写的不写。素材包里的引文是唯一证据来源
- 不写「为什么」（那是二次解释的活）；调色盘只写「怎么运作」

## 七、自检（写完必须跑）

```powershell
cd C:\tavern_helper_template
node src/兽血沸腾/tools/check-yaml.mjs
node src/兽血沸腾/tools/check-ejs.mjs
node src/兽血沸腾/tools/check-banned.mjs
```

三个脚本都必须零报错（注意 `check-yaml` 的运行总数会变化，只要 `fail=0`）。
另外注意：多阶段文件被 `check-yaml` 计入 `skipEJS`，属正常。

逐条自查：
1. 破折号 0 处
2. 禁用词表 0 处
3. 八股黑名单 0 处
4. 无占位符
5. 无 ASCII 双引号
6. 无 `因为 / 本质上 / 其实 / 内心`
7. 无 XML 标签
8. 多阶段文件首行是 `@@private`，且装饰器后**没有空行**；条件边界不重叠不遗漏
9. 不引用不存在的 MVU 路径（果果/壹条用 `魔宠.X.忠诚`；安度兰长老/隆美尔/李察王子不写 EJS）
10. 不与其他条目重复
