# 兽血沸腾 · 条目写作派发规范

本文件是派发给写作子代理的公共约定。每个子代理只写自己名下的文件，**不得运行 forge patch**（注册由主代理负责）。

## 一、必读顺序（缺一不可）

1. `src/兽血沸腾/design-spec.md` —— 卡的总体设计
2. `src/兽血沸腾/术语纪律.md` —— 你必须遵守的用词纪律
3. `src/兽血沸腾/tools/转化执行规范.md` —— 转化规范
4. `.skills/tavern-cards/references/rules.md` —— 写作规则
5. `.skills/tavern-cards/references/rules-check.md` —— 禁用模式清单
6. 按条目类型再读对应的规范文件：
   - 世界观 → `entry-types.md` 的世界观部分
   - 地理 → `entry-types.md` 地理部分 + `geography.md`
   - 时间线 → `entry-types.md` 时间线部分 + `timeline.md`
   - 角色 → `entry-types.md` 角色部分 + `basic-info.md` / `personality-palette.md` / `tri-faceted.md` / `multi-stage.md`
   - NPC → `entry-types.md` NPC 部分 + `npc.md`
   - 事件 → `entry-types.md` 事件部分

## 二、素材包

每个条目的素材来源是 `src/兽血沸腾/故事大纲.yaml`（原作 764 章的转化产物，含 `worldview` / `chapters` / `regions` / `factions` / `characters` / `items` / `important_chapters` 各段），按条目的 `keywords` 检索命中段落即可，包含：

| 键 | 含义 |
| --- | --- |
| `关键词` | 本条目使用的检索词 |
| `命中统计` | 各段命中条数 |
| `worldview` | 世界观段落（原作事实陈述） |
| `chapters` | 章节摘要（`[章名] 摘要`） |
| `regions` / `factions` / `characters` / `items` | 命中段落，带 `[名称]` 前缀 |
| `important_chapters` | 重要章节的剧情原因与原文引文 |
| `实体_区域` / `实体_势力` / `实体_角色` / `实体_物品` | 与条目名精确匹配的完整实体 |
| `章节窗口明细` | 仅事件条目：窗口内逐章 `idx / name / notes` |
| `窗口内引文` | 仅事件条目：窗口内重要章节引文 |
| `可复用旧节点` | 仅事件条目：上一版该窗口的节点，可参考改写 |
| `配角候选` / `候选详情` | 仅 NPC 条目：够格进编组的配角名单 |

素材包是**证据**，不是成文。你要把它压成条目格式，不是抄进文件。

## 三、硬性约束

### 格式
- UTF-8 无 BOM，纯 LF 换行，禁止 TAB，2 空格缩进
- YAML 用**中文写法**，`键: 值` 冒号后必须有一个空格
- 数据库格式（`键: 值` / 列表），**不是散文**
- 全文简体中文；禁止繁体与日文汉字
- 禁止占位符（`待补`、`TODO`、`XXX`、`（略）`、`...`）
- **XML 标签只能出现在 `contents` 字段里，不能写进内容文件**
- YAML 里禁止 ASCII 双引号 `"`，需要引号时用 `「」` 或 `“”`
- 一个文件里禁止 `---` 分隔线（会破坏 YAML 解析）

### 用词纪律（违反即返工）
- **破折号 `——` 全文杜绝**
- 禁用词表（原作不存在，禁止使用）：`魔歌祭祀`、`战歌祭祀`、`英雄阶`、`传奇阶`、`魔幻法师`、`位阶`
  - 说阶位时用真实七阶：`风语祭祀` → `灵魂祭祀` → `战争祭祀` → `权杖祭祀` → `维安大萨满` → `十二主祭` → `红衣大祭司`
  - `神曲萨满`、`龙祭祀`、`红衣大祭司`、`刀圣`、`极道高手`、`自主狂化`、`沙罗曼祭祀`、`亚龙祭祀`、`星袍祭祀`、`幻兽祭祀`、`屠龙祭祀` 都是原作实有称号，可用
- 八股黑名单：`似乎`、`几乎`、`仿佛`、`如同`、`宛如`、`像小兽`、`投石入湖`、`心湖泛起涟漪`、`嘴角微微上扬`、`眼中闪过一丝XX`、`带着XX的口吻`、`陷入极大的恐惧`、`万念俱灰`
- 句式黑名单：否定转折（`不是A而是B`）、标签化、过度心理描写、空洞数字
- 禁止 `因为`、`本质上`、`其实`、`内心`（三面性与性格调色盘里尤其严格）
- 禁止元叙事：不写「本条目的作用是」「这是设定」「原作里」之类
- 禁止跨条目重复与跨条目引用：不写「见XX条目」「如上文所述」
- 不做主观评价：不写「极美」「波澜壮阔」「灿烂文明」这类空泛形容
- **禁止自造战歌名**。原作实有战歌：通灵战歌、狂化战歌、献祭战歌、淫亵战歌、祝福战歌、吸血战歌、力量汲取战歌、洗浑战歌、心灵锁链战歌、石肤战歌、狂暴战歌、灵魂锁链战歌、致幻战歌、单控战歌、默发战歌、辉煌战歌、嗜血战歌；另有 `剑胆` 与 `琴心` 两首通灵副本战歌（是两个字的本名，**不得写作「琴心战歌」**）。`禁空之歌` 是斯迈族天鹅的**种族异能，不是战歌**。

### 内容纪律
- 只写**会让 AI 出错**的差异信息。通用常识、能从设定推导出来的内容一律不写
- 每句话过四问：这句话是原作事实吗？删掉会不会让 AI 出错？是不是在堆形容词？有没有具体画面或数字？
- 角色外貌只写特征，背景只写关键事件，关系写具体画面，行为展现性格，一句一意
- 不许编造。原作没写的就**不写**，绝不虚构。例如：主角肉身原主的姓名与死因、海加尔战役的精确纪年、「领域」的完整分级表、小空的父母、四件随身装备的品阶、淡水美人鱼族长与花精灵族长的姓名、忆苦与思甜的生母（原作前后自相矛盾）
- **比蒙总人口原作有明确数字：六百万**（L38722/L44454/L51878）；在编祭祀仅九百名，五大军团约一百名战争祭祀、每联队一名。这一类数字要用，不要当成缺失项
- 已知原作里两种说法并存的（五大贵族 / 六大贵族），**统一采用一处**：写「五大贵族」

## 四、自检（写完必须跑）

```powershell
cd C:\tavern_helper_template
node src/兽血沸腾/tools/check-yaml.mjs
node src/兽血沸腾/tools/check-ejs.mjs
node src/兽血沸腾/tools/check-banned.mjs
```

三个脚本都必须零报错。此外逐条自查：

1. 破折号 0 处
2. 禁用词表 0 处
3. 八股黑名单 0 处
4. 无占位符
5. 无 ASCII 双引号
6. 无 `因为 / 本质上 / 其实 / 内心`
7. 无 XML 标签
8. 数字与专名与素材包一致
9. 不与其他条目重复

## 五、交付

完成后用 `send_message` 向主代理报告：

- 写了哪些文件、各自行数与字节数
- 三个校验脚本的结果
- 自检清单逐项结果
- 任何与原作或规划冲突、你自己做了判断的地方（必须显式列出）

## 六、密度要求

条目要**厚**。参考量级：

| 类型 | 目标 |
| --- | --- |
| 世界观 | 3 KB 以上，按小节分，每节 3 到 6 条事实 |
| 地理·区域 | 3 到 5 KB，含区域概述、地点与场景列表、势力分布 |
| 地理·场景 | 2 到 3 KB |
| 地理·势力 | 3 到 5 KB，含势力构成、领地、关键成员、与主角的关系 |
| 时间线·history | 3 KB 以上，逐节点写，每节点含时间、事件、后果 |
| 角色·基础信息 | 5 到 8 KB，四部分：基本信息 / 外貌特征 / 背景设定 / 能力与关系设定 |
| 角色·性格调色盘 | 5 KB 以上，底色 / 主色调 / 点缀 / 衍生 + `总结: |` |
| NPC | 2 到 4 KB，每人 身份 / 外貌 / 说话方式 / 行为习惯 / 与主角的关系 |
| 事件 | 每节点 触发 / 地点 / 在场 / 经过 / 玩家可接（2 到 3 条纯方向），节点数按窗口内重要章节走 |

宁厚勿薄。写不动就回素材包里再挖，不要靠形容词凑字数。
