## 二、注册架构（已定，不可改）

### 2.1 `私密.yaml` —— XML 包裹的静态条目

证据基准：`src/怨妇救赎/世界书/角色/林曼云/私密.yaml`（打包后行 1 `---`、行 2 `<character_other character="林曼云">`、末行 `</character_other>`），`src/不要玩弄我的鸡吧-forge`、`src/欲望都市` 同形。

注册叶子（由主 agent 执行，**你不要注册**）：

```json
{
  "op": "add",
  "path": "/entryManifest/角色/{角色}_私密档案",
  "value": {
    "scope": "specific",
    "part": "other",
    "keywords": ["{角色}", "{第二关键词}"],
    "abstract": "…",
    "contents": [
      { "content": "---\n<character_other character=\"{角色}\">" },
      { "file": "世界书/角色/{角色}/私密.yaml" },
      { "content": "</character_other>" }
    ]
  }
}
```

**因此 `私密.yaml` 自身绝不能出现 `@@` 装饰器。** 一旦出现，打包时它会被挤到 XML 开标签之后（违反 `references/ejs/guide.md` L178「`@@` 装饰器必须在文件首行」）。


### 4.1 外观逐部位要求

**16 个通用部位一个都不能少。** 每项 1-3 句，必须给出：

- **尺寸/形制**（罩杯、颜色、形状、毛量、褶皱密度……）
- **触感**（手感、温度、软硬、阻力）
- **反应**（碰到会怎样、动情后会怎样）

参考已确认的原文词汇（`.skills/tavern-cards/tavern-cards/references/contents-creation/writing-style.md` §三 要写：逼、屄、骚逼、奶子、奶头、鸡巴、屁眼、肏、插、捅、射；不要写：私处、那里、下面、花径、阳具、下体）。

**弹药库**（同目录 `writing-style/`）：
- `文风词库-通用.md` —— 二十类通用词库（女体三处 / 口足腋 / 男体 / 体液 / 气味 / 触感 / 脏形容 / 状态 / 比喻 / 称呼 / 羞辱 / 畜化 / 公开 / 异物 / 血 / 动作 / 声音），每类按脏度分级。
- `语料-母猪世界书.md` —— 淫语 / 部位特写句式参考。
- `文风-母猪三级.md` —— 轻（暗示）/ 中（侵犯）/ 重（交合）三段完整片段。

**本卡定档 = 直给**（`design-spec.md` L64-68：NSFW 全开贴近原作、露骨直白、不做含蓄化改写）。所以主要参考 `文风词库-通用.md` 与 `语料-母猪世界书.md`。

**每个部位都必须写，不许合并，不许省略成"同上"。**

### 4.2 三、四、五、六段

- **气味**：体味（她的专属香味）、逼味、动情味（动情后气味怎么变）、汗、经水。必须能对上原文——凝玉是"大白兔奶糖"式的甜味，别人的甜味要换说法。
- **分泌物**：爱液（来得快慢、颜色、黏度、量）、初夜、奶水、眼泪。
- **敏感带**：9-10 项，每项写"碰了会怎样"的**具体反应**，不是"敏感度高"。
- **名器**：`名目` 是四字词（雅称，如"探骊得珠""玉壶冰"），`由来` 说清她为什么是这名器（种族天赋/身体构造/经历），`表现` 是进入后的实际体感，`代价` 是她要付出的（体力/精神/后遗症），`名声` 是外界怎么传她。
- **性癖**：5-6 项，每项一个小标题 + 具体行为。

## 六、写作红线（`references/rules-check.md` + `references/rules.md`）

### 6.1 必须遵守

1. **全文简体中文**，YAML 数据库格式（`键: 值`），2 空格缩进。
2. **一句一意**，短句为主。
3. **禁止占位符**：不得出现 `待细化`、`TODO`、`XXX`、`…`（作为省略）。
4. **禁止破折号 `——`**（全文杜绝）。
5. **禁止八股微表情**：`嘴角微微上扬`、`眼中闪过一丝 XX`。
6. **禁止模糊词**：似乎 / 几乎 / 仿佛 / 如同 / 宛如。
7. **禁止陈旧比喻**：像小兽 / 投石入湖 / 心湖泛起涟漪。
8. **禁止否定转折句式**：`不是[^，。]{1,20}，而是`。（`因为` **不** 在禁词表里，可以正常用。）
9. **禁止跨 EJS 阶段引用**：`aff < 20` 块内不得提及任何其他阶段的标识或内容。条件块之间互相不可见。
10. **`@@` 装饰器与本行内容之间不能有空行。一个条目只使用一个装饰器。**

### 6.2 交付前自查

```bash
grep -n -E "那里|下面|私处|那一块|那个地方|某个部位|点到为止|含蓄" 世界书/角色/{角色}/私密.yaml 世界书/角色/{角色}/私密阶段.yaml
grep -n "——" 世界书/角色/{角色}/私密.yaml 世界书/角色/{角色}/私密阶段.yaml
grep -n -E "似乎|几乎|仿佛|如同|宛如" 世界书/角色/{角色}/私密.yaml
grep -n -E "不是[^，。]{1,20}，而是" 世界书/角色/{角色}/私密.yaml 世界书/角色/{角色}/私密阶段.yaml
```

**全部必须无输出。**
