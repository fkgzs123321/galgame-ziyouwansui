# NPC 前向剧透整改 · 证据与规则

## 背景

`src/兽血沸腾/世界书/NPC/` 下的条目由原文「群像」段落拆分而来，因此**逐字照抄了后期剧情**。
玩家可能在第一章就读到这些条目，于是提前得知某人的后期头衔、死亡、结局。

审计方法：把条目字段里的中文片段拿去原文里统计首次出现章节，与该 NPC 本人首次登场章节比对。
**内容年代显著晚于登场章节的「身份变动 / 结局 / 后期头衔」表述，就是前向剧透。**

## 硬规则（必须遵守）

1. **只改这五个字段**：`身份`、`核心特质`、`关系`、`态度`、`互动方式`。
   `姓名`、`性别`、`外貌特征`（`整体印象`/`关键特征`）、`性格核心.行为模式`、`语言特征`（`说话风格`/`参考语料`）**一律不许动**。
   - 例外：`性格核心.核心特质` 是一句压缩摘要，若其中含剧透词，可同步改；但 `行为模式` 的逐条原文不许动。

2. **`参考语料:` 是原文逐字引用，绝不允许修改、删除、改写、重排。**

3. **绝对不许编造新剧情**。整改手段只有两种：
   - **删除**带剧透的从句 / 分号段（首选，最安全）；
   - **把「后为…」「此后…」「最终…」这类结局式表述改成登场时即成立的状态**（例如 `后来做到翡冷翠骑士团团长` → 直接删掉这半句）。
   没有原文依据的新信息一律不许写。

4. 删除后如果某个字段整行为空，**整行删掉**（包括缩进和冒号）。`关系` 字段必须留下内容——若删空，
   改写成该 NPC **登场时**与刘震撼/翡冷翠的关系（用该文件自身或原文已有的早期描述，不许新编）。

5. 保持 YAML 合法：两空格缩进、冒号后一个半角空格、不引入 `#` 注释、不使用 `——`（破折号，全卡禁用）。

6. **不要运行任何 forge / pack / configure 命令**，不要碰 `tavern-cards-state.json`。
   改完文件即止，向主 Agent 汇报。

## 章节时间轴（用于判断「晚」）

- 全书 764 章（去重后），`剧情.章节序号` 取值 0~763。
- 常见开局点：ch73（受封翡冷翠领主）、ch245（扩张期开始）、ch463（爱琴之花登场）。
- **只要某个表述的原文首现章节**晚于**该 NPC 首次登场章节 40 章以上，就要处理。**

## 已排除的误报（不要改）

- **`永贝里.yaml`**：`永贝里` 在原文里是**同名两人**——ch106 是盐魔首领（只出现 2 行），
  ch240 起才是黄颌美杜莎刀圣。本条目描述的是后者，**内容年代正确，不必整改**。
- 纯外貌描写（体型、毛色、装备外观）即使措辞首次出现较晚也**不算剧透**，不要动。
