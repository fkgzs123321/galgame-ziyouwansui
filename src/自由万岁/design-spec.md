# Design Spec — 自由万岁

> 来源素材：71 集红果短剧《自由万岁》全剧情深度解析（用户提供，已保存为 `素材原文.md` 并转化为 `故事大纲.yaml`）。
> 本文件只记录大方向；MVU/EJS、条目级规划、变量结构等技术细节由 tavern-cards 项目创建阶段处理。
> **状态：已确认（v2）**——用户已对全部开放问题作出裁定，本文件为确认版。

## 项目定位

- **项目名称**：自由万岁
- **形式**：**角色卡（世界书内嵌）**【已确认】
- **来源类型**：短剧改编。素材为「剧情解析 + 场景化扩写」的混合材料，剧情框架与事件节点忠于原剧，心理与对话为文学化扩展
- **主题**：现实向都市阶层寓言。剧名是反讽——「自由万岁」喊出之时即是坠落开始之时
- **体验目标**：让玩家沉浸于「自由与代价」的主题：见证或介入沈知意的自毁式坠落、林清禾的朴素崛起，以及陆司砚式克制人格的展开
- **情感落点**：现实向的沉重与反讽；短剧式爽感（打脸、逆袭、命运对照）与道德反思并存。素材明确指出沈知意并非纯粹的「坏人」——灰度是本作的核心价值

## 世界观概念

- **舞台**：架空现代中国县城「林县」，无超自然设定，现实性基线为真实架空（三到四个月的时间跨度，不锚定具体年份）
- **阶层结构**：以陆家（陆氏控股集团）为首的少数家族掌控经济资源与话语权；城西老城区是修车铺、出租屋、小饭馆的底层世界。核心冲突围绕「豪门」与「底层」两个空间展开
- **陆家庇护网络（全剧困境引擎）**：订婚珠宝、黑卡、专车、别墅门禁权限、依附的合作项目、信用担保、沈母 VIP 病房续费——七项资源一次性收回即代表彻底决裂。任何涉及沈知意经济困境的情节都可从这七个维度寻找逻辑支撑
- **职场生态**：惠丰金融以业绩为导向，实行新员工转正制度，转正名单是「审判时刻」
- **空间符号**：别墅宴会厅 ↔ 漏水出租屋；红酒 ↔ 白粥榨菜老干妈——道具即「自由」的具象化
- **收养前史**：沈知意幼年丧父（沈建平车祸身亡）被陆家收养，其母苏晚晴由陆家安排长期住院——陆家的恩情与沈知意心中的「控制」同源

## 角色方向

| 角色 | 身份 | 弧光方向 | 核心冲突 |
|------|------|----------|----------|
| 沈知意 | 陆家养女 → 实习生 → 无业 | **沉沦**（自毁式自由） | 追求自由 vs. 逃避责任 |
| 陆司砚 | 陆家独子、陆氏控股集团继承人 | **守恒**（克制与边界） | 尊重选择 vs. 内心伤痛 |
| 林清禾 | 惠丰金融新员工 | **成长**（朴素奋斗） | 努力 vs. 被嘲讽 |
| 周燃 | 周记汽修小老板 | **守恒**（寄生型，永不改变） | 甜言蜜语 vs. 实质行动 |
| 赵媛 | 新员工、小跟班 | 审时度势 | 站队 vs. 自身利益 |

配角：陆振邦与温惠茹（陆父陆母，伤透心的养父母）、苏晚晴（沈母，代价承受者，无声角色）、何广泰（总经理）与郑凯（经理）、陆家别墅门卫。

角色间张力：阶层张力（豪门 vs 底层）、情感三角（沈知意 → 陆司砚 ← 林清禾，克制不滥情）、寄生关系（周燃 → 沈知意的情绪价值陷阱）。

沈知意的人设纵深（四层）：表层骄纵理所当然 → 深层养女自卑 → 病态的情绪价值渴望 → 用新错误掩盖旧错误的自我毁灭式执念。周燃的功能是镜子：照出「她选择的不是爱情，而是一个只会消耗她的人」。

- **`<user>` 定位**【已确认：玩家可扮演任何人】：玩家以自选身份的原创角色进入剧情——惠丰金融员工、陆家亲故、城西熟人、周燃社交圈、或任何剧情中的在场者均可。开场时确定身份，之后身份即固定为该角色的社会位置；强剧情锚点不因玩家身份改变，但玩家的视角、信息获取与人际距离随身份变化
- 与 `<user>` 的初始关系：由所选身份推导（如惠丰金融同事=职场平行线，陆家亲故=可旁观决裂全程）

## 互动与动态需求

- **玩家能动性**【已确认：强剧情驱动 + 允许分支】：主线沿六阶段推进，十个关键节点为固定事件锚点（泼酒退婚、收回资源、转正名单、道歉被拒、母亲病危……），不因玩家行为跳过或颠倒；玩家自由度体现在锚点之间的日常互动、自身视角的经历与人际经营；**分支**作用于支线与结局变体
- 分支空间（建议，供创作规划细化）：沈知意是否触底反弹、周燃是否败露或得逞、林陆感情线的快慢、玩家身份线自身的命运
- 建议追踪的动态概念（供后续创作规划参考，非最终方案）：沈知意的资源/债务状态（七项资源、网贷利息）、剧情阶段进度、与各角色的关系变化、林清禾线进度（收入对比是量化标尺：月入五万 vs 四千五）
- 反馈循环节奏：短期职场事件 + 长期阶段推进（原剧 71 集的体量适合长线养成式追踪）

## SFW / NSFW

- **分级**【已确认：NSFW 允许】：成人内容允许出现；鉴于素材本体为全年龄短剧，NSFW 定位为**剧情中可自然触发的成人内容**（跟随关系与剧情推进），而非每楼必现的硬核主线
- 性向与关系结构：随玩家可扮演任何人的设定保持灵活，不做预设限制
- **安全底线**：用户未列出硬性边界清单，按通用底线处理——未成年人、非自愿、乱伦等内容一律不出现；此为默认配置，用户可随时补充或调整
- 题材注意：网贷、母亲病危、心理崩溃、情感操控属沉重内容，呈现需有分寸；周燃的「情感诈骗」写法是心理层面而非猎奇层面

## 剧情设计

**六阶段主线**（原剧 71 集，跨三到四个月）：

1. 订婚宴决裂（第1-5集）：泼酒退婚，陆家收回资源
2. 落差初现（第6-15集）：出租屋、入职惠丰金融、画大饼日常
3. 职场挣扎（第16-35集）：转正落选、质问陆司砚、客户流失、林清禾崛起
4. 全面崩溃（第36-50集）：道歉被拒、母亲病危、网贷缠身
5. 触底与转折（第51-65集）：至暗时刻、林陆感情升温、沈知意反思
6. 结局（第66-71集）：命运收束

**十个关键节点**：订婚宴泼酒 → 搬进出租屋 → 转正名单公布 → 质问陆司砚 → 客户全面流失 → 道歉被拒 → 母亲病危通知 → 林清禾拿下项目 → 陆家拒门 → 月入五万 vs 四千五。

**复杂剧情的控制策略**：
- **锚点不可逆**：泼酒退婚、陆家收回资源等关键节点为固定事件锚点，锁定阶段推进；「七项资源清单」用作阶段门控
- **暴露时机**：周燃的寄生本质分三阶段揭示（画大饼日常 → 病危时「我手上没钱」 → 关系名存实亡仍不离开）；沈知意的四层心理逐层剥开；陆家收回资源的完整清单在阶段一末尾一次性亮出，作为后续所有困境的解释基础
- **双线对照**：沈知意线下行线与林清禾线上行线共用同一舞台（惠丰金融），以收入与地位差距做量化对照
- **分支策略**【已确认允许分支】：锚点内的核心事件结果固定，锚点之间的过程与关系状态可被玩家改变；分支在阶段边界结算，产生支线变体与结局变体（如沈知意的反思是否到来、玩家身份线的个人结局）

## 风格意向

【已确认：文风都要——两者结合】

- **对白**：忠实短剧风——直白、强冲突、金句化（「你不是要自由吗？这就是自由。」「等以后等以后，你什么时候才能不等以后？！」）
- **叙述**：文学化笔触——心理描写为主（沈知意的自我催眠、陆司砚的克制、林清禾的自尊），环境描写服务于阶层对照（别墅/出租屋）
- **情绪基调**：现实压抑渐强，反讽为底色，沉重中带爽感
- **叙事视角**：第三人称，紧贴玩家视角所见所闻；玩家以自选身份在场

## 开场构思

【已确认（按用户意向定案，可再调）】

- **开场情境**：订婚宴泼酒夜（原剧第 1 集，冲突爆发点）——高浓度开场，一次性抛出人物关系与核心矛盾
- **入场方式**：叙事式开场内嵌身份自选——玩家先选择自己的身份（惠丰金融员工/陆家亲故/城西熟人/宴会宾客等），以该身份亲历订婚宴之夜，从此进入强剧情主线
- **开场信息密度**：渐进揭示——首场只给「豪门宴会 + 突发泼酒」的场面，养女前史、资源清单、人物底色随剧情逐层展开
